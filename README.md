# Student Result Using Union in C

## Project Description

A simple C program that demonstrates the use of a union for storing student result information. The program allows the user to enter either marks or a grade and displays the selected value.

## Features

- Enter student marks
- Enter student grade
- Display the selected result
- Demonstrate how a union stores one value at a time
- Simple menu-driven program

## Technologies Used

- C
- Union
- Conditional Statements
- Standard Input/Output

## How to Run

1. Create a file named `student_result_union.c`.
2. Compile the program using a C compiler.
3. Run the compiled program.

Example using GCC:

```bash
gcc student_result_union.c -o student_result_union
./student_result_union
